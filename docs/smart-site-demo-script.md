# 智慧工地 · 任务演示脚本（新建 → 已完成）

以「智慧工地管理系统」为业务场景，从新建一条任务开始，逐步操作到任务已完成。全程人工只做发起与审核，中间执行由专家团智能体完成，核心看点是任务与 AI 会话联动、六阶段推进与人工审核门禁。

## 准备

1. 环境二选一：双击 `dist/index.html`，或 `npm run dev`（端口 5199）。
2. 登录账号 `owner`，密码 `lingee520`（管理员「吴宏超」）。
3. 建议用浏览器隐身窗口；需要重来时换一个新隐身窗口即可。
4. 任务可挂在任一现有项目；如需完整工地场景，可先在「协作开发 → 项目」页签新建项目「智慧工地管理系统」（负责人张工，专家团选「通用应用开发专家团」）。

## 操作步骤

### 第 1 步：打开新建任务弹窗

侧边栏「协作开发」→「任务」页签（默认激活）→ 工具栏「新建任务」。

### 第 2 步：填写任务信息

| 字段 | 填写 |
| --- | --- |
| 标题 | 塔吊安全监测告警模块开发 |
| 描述 | 接入塔吊黑匣子实时数据（风速、力矩、幅度、倾角、载重），超限按预警/报警/断电三级告警并推送值班安全员，支持处置闭环（确认→处置→复核）与月度安全报表 |
| 状态 | 待开始（默认） |
| 优先级 | 高 |
| 项目 | 智慧工地管理系统 |
| 处理人 | 张工 |
| 标签 | 需求 |

### 第 3 步：选择专家团与产物确认人

展开专家团下拉，悬停「通用应用开发专家团」行 → 右侧二级面板列出六个交付阶段，为各阶段指定产物确认人：需求分析→赵琳、编码实现→张工、测试验证→陈晨（其余可留默认）。

### 第 4 步：保存

点「保存」→ toast「创建成功」，任务出现在看板「待开始」分组。

### 第 5 步：开始执行

点任务卡片右上 ▶（开始执行）→ 状态变「进行中」，自动跳转 AI 对话页（输入框已携带任务引用）→ toast「已进入需求分析，请在 AI 对话中推进」。

### 第 6 步：查看执行动态

回「协作开发 → 任务」，点任务卡片打开详情抽屉，依次讲解：执行概览（六阶段进度，需求分析「正在工作」）、运行记录（思考 / 执行 / 结果，展开看步骤详情）、各阶段产物确认人。

### 第 7 步：需求分析 · 提交审核

点详情头部「提交当前节点审核」→ 状态变「审核中」→ toast「需求分析已提交审核」；执行概览「需求分析」旁出现「下一步 / 修改」按钮。

### 第 8 步：需求分析 · 审核通过

点「下一步」→ toast「审核通过，进入方案设计」，自动跳回 AI 会话。

### 第 9 步：方案设计 · 提交审核

回任务详情（侧边栏「协作开发」→ 任务 → 点任务卡片）→ 点「提交当前节点审核」→ toast「方案设计已提交审核」。

### 第 10 步：方案设计 · 审核通过

点「下一步」→ toast「审核通过，进入实现规划」，自动跳回 AI 会话。

### 第 11 步：实现规划 · 提交审核

回任务详情 → 点「提交当前节点审核」→ toast「实现规划已提交审核」。

### 第 12 步：实现规划 · 审核通过

点「下一步」→ toast「审核通过，进入编码实现」，自动跳回 AI 会话。

### 第 13 步：编码实现 · 提交审核

回任务详情 → 点「提交当前节点审核」→ toast「编码实现已提交审核」。可停留讲解该阶段的运行记录与产物文件。

### 第 14 步：编码实现 · 审核通过

点「下一步」→ toast「审核通过，进入测试验证」，自动跳回 AI 会话。

### 第 15 步：测试验证 · 提交审核

回任务详情 → 点「提交当前节点审核」→ toast「测试验证已提交审核」。可停留讲解验证结论。

### 第 16 步：测试验证 · 审核通过

点「下一步」→ toast「审核通过，进入部署交付」，自动跳回 AI 会话。

### 第 17 步：部署交付 · 提交审核

回任务详情 → 点「提交当前节点审核」→ toast「部署交付已提交审核」。

### 第 18 步：部署交付 · 审核通过，任务完成

点「下一步」→ toast「最终节点审核通过，任务已完成」；任务状态变「已完成」，详情抽屉保持打开，执行概览六阶段全部完成。

### 第 19 步：收尾回看

在任务详情依次展示：状态流转历史、各阶段产物文档预览、「我的会话」里的执行会话记录，完成演示。

## 可选分支：退回修改

任一阶段处于「审核中」时，用「修改」代替「下一步」→ 任务退回「进行中」并切回 AI 会话，toast「已退回修改，可在会话中二次修改」；补充要求后重新提交审核即可继续推进。

## 附录：状态与反馈对照

| 状态 | 触发操作 | 系统反馈 |
| --- | --- | --- |
| 待开始 | 卡片 ▶ 开始执行 | 「已进入{阶段}，请在 AI 对话中推进」 |
| 进行中 | 提交当前节点审核 | 「{阶段名}已提交审核」 |
| 审核中 | 下一步 / 修改 | 「审核通过，进入{下一阶段}」；最终阶段「最终节点审核通过，任务已完成」；退回「已退回修改，可在会话中二次修改」 |
| 已完成 | — | 执行概览六阶段全部完成 |

## 常见问题

- 刷新后任务还在吗？在，任务存于浏览器本地（localStorage），刷新不丢。
- 想重置演示环境？换一个新隐身窗口即可。
- 新建任务的审核详情为通用文案（按任务标题动态生成）；只有内置种子任务带专属审核报告，属预期行为。
